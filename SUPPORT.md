# Support

Use the [GitHub issue tracker](https://github.com/tetsuji16/csv-edit/issues) for
confirmed bugs and focused feature requests.

## Before opening an issue

1. Update CSV Edit and Visual Studio Code to their latest available versions.
2. Check whether the problem also occurs with a small local test file.
3. Search existing issues for the same behavior.

## What to include

- CSV Edit version
- Visual Studio Code version
- Operating system
- File type and delimiter
- Clear reproduction steps
- Expected and actual behavior
- A minimal sample only when it contains no confidential or identifying data

Do not attach production data, credentials, personal information, access tokens,
private URLs, or proprietary records. Replace sensitive values with synthetic
examples before sharing a file or screenshot.

Security-sensitive reports should not include exploit details or secrets in a
public issue. Open a minimal issue requesting a private contact channel without
including sensitive content.
